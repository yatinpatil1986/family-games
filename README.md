# Family Games

Kid-friendly board games for family game night. Each game is a single HTML file: no install, no build step. Open it in a browser on any computer, tablet or phone.

## Games

### [Snakes & Ladders](snakes-and-ladders/)
The classic 100-square board with extras:
- **Power-ups:** shield (block a snake), sword (chop a snake for good), gun (shoot any snake), and mine (hide it on a square; whoever steps on it gets blasted to a random spot).
- **Helicopter:** lands on a random square for 6 turns. End your move on it or next to it and it flies you 2 rows up.
- Sounds, 2–4 players, and any mix of humans and computer players.

### [Dino Escape](dino-escape/)
A cooperative race: everyone works together to escape a T-rex across five stages.
1. Jungle Trail
2. Volcano Valley
3. Misty Swamp
4. Frosty Peaks
5. Crystal Cave

- After every round, the T-rex rolls its own die and stomps after you. The team shares 3 hearts.
- Shared backpack gear: bone, banana peel, pterodactyl ride, and rope to help a friend.
- Each bend has a signpost: take the wobbly bridge shortcut, or the long safe way.
- Three T-rex speeds: Sleepy, Hungry and Grumpy.

## Playing

- **Locally:** download a game's `index.html` and open it in a browser.
- **Online:** turn on GitHub Pages (Settings → Pages → deploy from the `main` branch, root folder). The games will be at:
  - `https://yatinpatil1986.github.io/family-games/snakes-and-ladders/`
  - `https://yatinpatil1986.github.io/family-games/dino-escape/`
